📝 전과목 퀴즈 도전하기 ➔

처음 시작한다면, 이 순서로

  1. 개념 잡기 · 주식·채권 → 경기·기업 분석 → 위험·포트폴리오. 용어를 자기 말로 설명합니다.
  2. 보기 구분하기 · 고객 보호·윤리 → 영업 규제 → 회사법·세제. ‘누가 / 무엇을 / 언제 / 예외’를 표시합니다.
  3. 계산하기 · 공식을 보지 않고 숫자를 대입합니다. %, %p, 배수, 원 단위를 답 옆에 씁니다.
  4. 회상하기 · 확인 질문에 먼저 답한 뒤 해설을 엽니다. 틀린 장은 퀴즈 → 핵심 노트 → 다음 날 재풀이합니다.

7일 압축 복습 예시 · 1~2일 개념·분석 / 3일 위험·계산 / 4일 윤리·고객 보호 / 5일 법규·회사법·세제 / 6일 전과목 풀이 / 7일 오답·공식 재현. 처음 배우는 경우 학습 기간을 늘리세요. 일정 자체는 합격 기준이 아닙니다.
